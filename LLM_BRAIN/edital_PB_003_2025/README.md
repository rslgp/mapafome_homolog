# Projeto MAPA FOME — Edital Social SEDH/PB nº 003/2025

## Arquivos

- `proposta.md` — fonte em Markdown, editável.
- `proposta.rtf` — versão formatada pronta para abrir no Word e salvar como `.docx`.

## Aviso importante

Este é um **RASCUNHO**. A extração automática do PDF do edital retornou conteúdo binário comprimido — não foi possível ler automaticamente todos os campos obrigatórios (valor máximo, prazo, eixos temáticos, documentos de habilitação, contrapartida).

Todos os trechos marcados com `[VERIFICAR NO EDITAL]` ou `[TODO]` precisam ser conferidos contra o texto oficial do edital **antes do envio**. Recomenda-se também:

1. Revisão jurídica por advogado(a) com experiência em MROSC (Lei 13.019/2014).
2. Validação do orçamento contra os limites de rubrica exigidos pelo edital.
3. Juntada da documentação de habilitação conforme anexos do edital.

## Como gerar `.docx`

**Opção 1 — Microsoft Word (sem instalar nada):**
1. Abra o Microsoft Word.
2. `Arquivo → Abrir` e selecione `proposta.rtf`.
3. `Arquivo → Salvar Como → Documento do Word (*.docx)`.

**Opção 2 — Pandoc (se já estiver instalado):**
```
pandoc proposta.md -o proposta.docx
```

**Opção 3 — LibreOffice Writer:**
1. Abra `proposta.rtf` no LibreOffice Writer.
2. `Arquivo → Exportar Como → .docx`.

## Estrutura adotada

A proposta segue o **Plano de Trabalho** exigido pela Lei 13.019/2014 (MROSC), que é a base jurídica para qualquer Edital de Chamamento Público estadual. Seções:

1. Identificação da OSC proponente
2. Identificação do projeto
3. Diagnóstico da realidade objeto da parceria
4. Objetivos (geral + específicos)
5. Metas, indicadores e meios de verificação
6. Metodologia
7. Cronograma físico
8. Orçamento e cronograma de desembolso
9. Equipe
10. Sustentabilidade pós-parceria
11. Contrapartida
12. Monitoramento e avaliação
13. Documentação de habilitação
14. Declarações

Se o edital SEDH/PB nº 003/2025 exigir **outra ordem** ou **campos específicos** (como formulário-modelo anexo), **priorize o formato oficial** — copie os conteúdos das seções deste rascunho para os campos do formulário exigido pela SEDH.
